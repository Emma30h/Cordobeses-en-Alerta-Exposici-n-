# Cordobeses en Alerta · Exposición

Presentación sobre el funcionamiento de la Dirección Monitoreo Cordobeses en Alerta.

## Cómo verla
1. Descargar el repositorio (Code → Download ZIP) y descomprimirlo completo.
2. Abrir `index.html` con Chrome o Edge. Funciona sin internet.
3. Teclas: flechas, espacio o clicker para avanzar · `F` pantalla completa.

## Contenido
- `index.html`: presentación (14 láminas).
- `media/`: fotos y videos seleccionados (pantallas con datos personales difuminadas).
- `fonts/`: tipografías locales (Barlow, Barlow Condensed, JetBrains Mono; licencia SIL OFL).
